# SQL Learning

Learning SQL by writing it — one query at a time.

## What's inside

- `SQLQuery1.sql` — DDL & DML fundamentals: creating databases and tables, `INSERT` / `UPDATE` / `DELETE`, `ALTER TABLE`, `TRUNCATE`, primary keys, and `ORDER BY`.

## How to run

Open `SQLQuery1.sql` in SQL Server Management Studio (or any T-SQL client) and run it top to bottom. Each block builds on the last.

Part of my learning-in-public journey as a data analyst — every concept here also shows up in my daily LinkedIn posts. Started October 2026.
